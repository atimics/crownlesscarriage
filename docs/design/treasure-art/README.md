# Treasure concept art

![Six Crownless treasure designs](treasure-concepts-v1.png)

The sheet shows Sun Reliquary, Ash Crown, Moon Cup, Saintless Torc,
Blackglass Icon and Ember Casket in reading order. It establishes their
silhouettes, worn materials and close details.

Generated on 8 September 2026 with the built-in image generation tool.
The [exact prompt](prompt.md) is retained with the image. The source output was
copied intact into this folder. Dimensions: 1536 by 1024 pixels, PNG.

Visual review confirmed six separate objects, correct labels, clear silhouettes,
the crown's three main points and repair, the cup's crescent handle, the torc's
open ends, the icon's pale figure, and the casket's red latch stone.

The sheet is concept art. [#487](https://github.com/atimics/crownlesscarriage/issues/487)
owns game models, individual cargo portraits, containers, asset packaging and
native/browser review. Keep the small portrait readable when adapting the
sheet's fine engraving. The [design](../treasure-and-loot.md) and
[interactive sketch](../treasure-and-loot.html) set out the player interaction.
