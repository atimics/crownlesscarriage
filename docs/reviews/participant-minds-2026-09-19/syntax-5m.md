# 5M dialogue acts

The new checkpoint predicts public meaning, and the existing human/Hra'khor
renderers supply the words. The C runtime accepts the versioned syntax prefix.
A native pair runner gives each person their own state and the public acts,
checks the returned act, and saves raw output before rendering it.

These are raw greedy generations, followed by validation. Evaluation preserves
the original generated bytes and any error. The full test evaluation used the
frozen repaired model after the sampled evaluation. The scope is distillation
of a small authored policy. This is a useful syntax/inference result, rather
than evidence about open-ended language quality.

## Coverage failure and repair

The first model passed its narrow test but generated `seek_paid_safe_work` in
the real Chenric/Harthild work exchange. Training histories had requests while
the live opening stated a need. That failed attempt is preserved in run one.
The repair generates histories with both openings and checks that earlier
self-reported needs fit the frozen own state. The final model completes that
same work scene, as well as Jory/Bren's safety scene and Ilyra/Tomas's food scene.
Those real scenes informed development and should remain development examples.

The later fresh-world check uses seeds 2201–2206 at days 1, 1, 15, 32, 91 and
181. It selects co-located people outside the earlier six participant IDs.
All six pairs complete five turns. The model stayed frozen. Full snapshots,
raw native output and the selection script are in `syntax-5m-fresh-worlds.json.gz`.

The repaired work exchange, from native inference:

> I need paid work.
>
> We could look for paid work together.
>
> Only if we agree the pay before starting work.
>
> Those terms suit me.
>
> Goodbye.

The model produces acts and reply indices for these lines. The renderer owns
the phrasing. Hra'khor uses those same acts and the existing native vocabulary.

## Data and provenance

Both datasets are explicitly synthetic state fixtures. A stable hash assigns
whole own-state combinations to splits. Exact model inputs are disjoint. The
repair dataset has 400 combinations and 10,300 rows; needs, goals, courage,
coins and public histories vary. Model features include hunger and distress
predicates, matching the procedural rules. Most decision patterns are shared
across splits, with variation in other state fields. This tests learning the
finite policy, with limited claims about new situations.

Run one trained 1,200 steps in 256 seconds. Run two warmed from that export for
800 steps. Both use the same 4,945,153-parameter architecture, native tokenizer,
batch eight and seed 19. The archives contain full datasets, source hashes,
trainer source, per-step logs, raw evaluations, native receipts and real scenes.
The temporary full-test script initially imported an unrelated `/tmp/timeit.py`;
the saved failure log records this. Isolated Python imports completed the test.

Six focused CTest suites passed, including native prefix/token checks. Seven
training/runner contract tests and 13 existing participant compiler tests passed.
The standalone builder was also exercised with the exported checkpoint.
