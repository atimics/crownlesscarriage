# Complete event grammar and release training

The account grammar has 158 rules covering all 139 declared event kinds.
The coverage guard requires a rule for each kind and verifies source patterns
against simulation message formats. Historical ambush wording has a source
commit fixture. Quest progress now emits a real event on an evidence-backed
advance, with the evidence as its parent.

Native tests passed for 316 rendered forms and 474 inverse forms, including
field spans, quantities, optional actor omission, open detail payloads and
byte limits. The parser now searches bounded separator choices for names such
as Willow Republic and St. Ilyra before a quantity. A 4096-attempt limit bounds
matching work. Fourteen focused CTest suites passed, including old checkpoint
loading, semantic inputs, diagnostic data, quest events and the coverage gate.

The event fact bridge uses current participant accounts, owner-bound references,
source, day, confidence and explicit knowledge certainty. Private accounts stay
private. A different retelling keeps its own uncertainty. It quotes known text
for report, ask and warn acts.

The release workflow selects changes relevant to dialogue, training and its
native runtime on version tags, and supports manual runs. CPU training uses
pinned dependencies and a pinned ZERO commit. The workflow keeps a model only
after all test cases match and all native outputs match Python. The local
800-step run passed 1018 policy cases and 1018 native comparisons. The job has
a 20-minute limit and training has an 8-minute limit. Failure artifacts are
retained for 14 days; verified model artifacts for 90 days.

This covers event kinds and their supported message forms. Further wording
variants and distorted retellings can require more rules. The compact learned
policy still has seven moves; event-selection training and game integration
build on the new fact bridge. The 67 command kinds, relationships and memories
remain separate coverage dimensions.
