# Design Decision Log

Major changes to creative or technical contracts receive a short decision
record. Records preserve the reason behind a constraint so future work does not
accidentally reintroduce rejected scope.

## Record template

Each record should include:

- Status
- Context
- Decision
- Consequences
- Rejected alternatives
